Necesse Steam Workshop 上架清单（Origami 五件套）
================================================

前置
----
1. Steam 已登录，拥有 Necesse
2. 完全退出游戏（不要从 Steam 正常开，要用下面的脚本）
3. 一次只传一个；传完关掉游戏再传下一个

推荐顺序
----
1. HelpfulNPCs
2. ItemBrowser
3. VeinMiner
4. AutoTrash
5. SettlerAffix

每个 mod 怎么传
----
在文件夹：
  %APPDATA%\Necesse\origami-necesse-mods

运行（例）：
  python launch-for-upload.py HelpfulNPCs

进游戏主菜单 -> Mods -> 选中该 mod（确认已启用）-> Upload

首次上传默认 Hidden（仅自己可见）。到 Steam 工坊页面：
  - 标题用 steam_workshop/<Mod>/title.txt
  - 描述粘贴 en.txt（建议再贴一段 zh-CN.txt）
  - Visibility 改成 Public
  - 封面已是 jar 里的 preview.png，可在工坊页再换更大图

联机
----
五个都不是纯客户端。房主和加入者都建议安装同一套。

版本
----
游戏 1.3.3 / 模组见各文件夹 / 作者 Origami
